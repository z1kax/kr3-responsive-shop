# KeyStore - адаптивный интернет-магазин клавиатур

## Описание проекта
Проект представляет собой адаптивную версию многостраничного сайта интернет-магазина клавиатур. Основой послужил проект, разработанный в рамках Контрольной работы №1. В данной работе проект был переведен на качественно новый уровень за счет внедрения адаптивной верстки и обеспечения базовой доступности интерфейса.

**Тема КР №3:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

**Ссылка на опубликованный проект (GitHub Pages):** https://z1kax.github.io/kr3-responsive-shop/

## Структура проекта
* `index.html` - главная страница;
* `catalog.html` - страница каталога;
* `product.html` - карточка товара;
* `order.html` - страница оформления заявки;
* `contacts.html` - страница контактов;
* `css/style.css` - базовые стили (из КР №1);
* `css/responsive.css` - стили адаптивности (Mobile First);
* `js/main.js` - базовая интерактивность (модальное окно, валидация);
* `images/` - папка с изображениями;
* `lighthouse/` - отчеты аудита доступности;
* `README.md` - описание проекта.

## Адаптивные решения
* **Подход Mobile First:** базовые стили написаны для мобильных устройств, расширения добавляются через `@media (min-width: ...)`.
* **Медиазапросы:** проект проверен и адаптирован под ширины 360px, 430px, 768px, 1024px и 1440px.
* **Сетка (Grid и Flexbox):** карточки товаров перестраиваются с 1 колонки на мобильных до 2 на планшетах и 3 на десктопах. Каталог на мобильных выстраивается в одну колонку, на десктопе фильтры уходят в сайдбар.
* **Навигация:** на мобильных устройствах меню выстраивается в центрированную колонку, на десктопе - в горизонтальную строку.
* **Адаптивные изображения:** реализовано базовое правило `max-width: 100%`, а также использованы атрибуты `srcset` и `sizes` для оптимизации загрузки картинок на разных экранах.
* **Адаптивные таблицы:** таблица характеристик на странице товара обернута в контейнер `.table-wrapper` с горизонтальной прокруткой, чтобы не ломать макет на телефонах.
* **Типографика и кнопки:** размеры шрифтов заголовков и кнопок плавно масштабируются с помощью функции `clamp()`. Кнопки в карточках растянуты на 100% ширины для удобства нажатия на сенсорных экранах.

## Доступность (A11y)
* **Семантика:** проверена структура страниц (наличие одного `h1`, использование `header`, `main`, `nav`, `footer`).
* **Клавиатурная навигация:** добавлен видимый фокус (`:focus-visible`) для всех интерактивных элементов.
* **Ссылка-пропуск:** добавлен `skip-link` для быстрого перехода к основному контенту.
* **Формы и изображения:** проверено наличие `label` у полей ввода и осмысленных `alt` у изображений.
* **Контрастность:** в ходе аудита Lighthouse были выявлены и исправлены проблемы с контрастом текста на бейджах товаров и ссылках в хлебных крошках.

## Проверка Lighthouse
В браузере Google Chrome был проведен аудит доступности (Accessibility) для всех страниц проекта (`index`, `catalog`, `product`, `order`, `contacts`). Оценка доступности составляет **100 баллов**. Сохраненные отчеты находятся в папке `lighthouse/`.
