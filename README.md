# KeyStore - учебный интернет-магазин клавиатур

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина клавиатур.

## Структура проекта

- `index.html` - главная страница;
- `catalog.html` - каталог клавиатур;
- `product.html` - карточка товара;
- `order.html` - страница оформления заявки;
- `contacts.html` - контактная информация;
- `css/style.css` - файл стилей;
- `js/main.js` - файл JavaScript;
- `images/` - папка для изображений;
- `README.md` - описание проекта;
- `.gitignore` - список файлов, исключённых из Git.

- HTML;
- CSS;
- Git;
- GitHub.

Проверены страницы:

- `order.html`;

- `product.html`.

Отчеты сохранены в папке `lighthouse`.

### Исправления доступности
В ходе аудита Lighthouse были выявлены проблемы с контрастностью:
1. Белый текст на оранжевом (Хит) и зеленом (Новинка) бейджах в карточках товаров.
2. Фиолетовые ссылки в хлебных крошках на сером фоне.
Проблемы были исправлены путем изменения цвета текста бейджа на черный, затемнения фона зеленого бейджа и добавления подчеркивания для ссылок в хлебных крошках.
